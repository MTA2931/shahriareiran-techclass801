# شهریار ایران - کلاس کار و فناوری

این پروژه شامل دو بخش برای کنترل و نمایش چشم‌های ربات با استفاده از ESP32 و نمایشگر OLED است.

## 📁 eyes

کدهای مربوط به طراحی و نمایش چشم‌های ربات روی نمایشگر OLED.

**قطعات مورد استفاده:**
- ESP32
- OLED Display

## 📁 touch

کدهای مربوط به حرکت چشم‌ها و تغییر حالت چهره ربات با استفاده از سنسور لمسی.

**قطعات مورد استفاده:**
- ESP32
- OLED Display
- Touch Sensor

**با لمس یا نگه‌داشتن سنسور Touch، چشم‌های ربات به حالت عصبانیت (Angry) تغییر می‌کنند.**
