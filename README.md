## 📁 فولدر eyes

کدهای مربوط به طراحی و نمایش چشم‌های ربات روی نمایشگر OLED.

**قطعات مورد استفاده:**
- ESP32
- OLED Display

## 📁 فولدر touch

کدهای مربوط به حرکت چشم‌ها و تغییر حالت چهره ربات با استفاده از سنسور لمسی.

**قطعات مورد استفاده:**
- ESP32
- OLED Display
- Touch Sensor

**با لمس یا نگه‌داشتن سنسور Touch، چشم‌های ربات به حالت عصبانیت تغییر می‌کنند.**
